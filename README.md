# Super Trasa

Gra rodzinna dla 5–6 latków: układanie sekwencji (puzzle) i budowa trasy z klocków. **Nie jest grą BoS / MetaBot Studio.**

```bash
cd super-trasa
npm install
npm run dev
```

Otwórz [http://127.0.0.1:5196](http://127.0.0.1:5196).

1. Wybierz kierowcę (zwierzątka / kostki / ludziki / zrób swojego).
2. 1️⃣ — tor do Studio TV.
3. 🚧 — szlaban przed metą.
4. 🏎️ — budowa gokarta i jedno okrążenie.

Assety z `super-trasa-assets.zip` są w `public/assets/`. Zipów nie commitujemy.
